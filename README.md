# Jmak_keys — Тренажёр мышечной памяти нажатия клавиши

![Jmak_keys Demo](https://eternitegik.github.io/Jmak_keys/) <!-- Замени на реальную ссылку после настройки GitHub Pages -->

Интерактивный веб-тренажёр для развития скорости и точности нажатия клавиш на клавиатуре. Проект написан на чистом HTML, CSS и JavaScript.

## ✨ Возможности

- **Гибкая настройка**: выбор наборов символов (буквы русского/английского алфавита, цифры, спецсимволы, F-клавиши, управляющие клавиши).
- **Настройка сложности**: регулировка количества циклов (от 5 до 100) и повторений каждой клавиши (от 1 до 10).
- **Режим реального времени**: отображение нажатой клавиши с цветовой индикацией (зелёный — верно, красный — ошибка).
- **Статистика**: по завершении задания выводится таблица с результатами: целевая клавиша, количество ошибок и среднее время нажатия.
- **Визуальная обратная связь**: отображение последовательности символов (опционально) и прогресса выполнения.

## 🚀 Быстрый старт

Просто открой файл `index.html` в любом современном браузере. Никаких дополнительных установок не требуется.

```bash
# Клонируй репозиторий
git clone https://github.com/Eternitegik/Jmak_keys.git

# Перейди в папку проекта
cd Jmak_keys

# Открой index.html в браузере
open index.html  # или просто дважды кликни по файлу
